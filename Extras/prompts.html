Manuales

La guía oficial de prompting, reordenada y aplicada a tus páginas interactivas. Se omitió lo que no aplica al diseño web (dosificación de medicamentos, migración de API, subagentes).

Memoria

Todo lo aprendido vive en un solo JSON que se sobrescribe en cada análisis. Guárdalo en Google Drive (vía Apps Script o archivo vinculado) para que siga mejorando entre dispositivos.

Estado

Nube · Google Apps Script

La URL y la clave se guardan solo en este navegador, nunca dentro del JSON.

Código del script y pasos de publicación
  1. Entra a script.google.com → Nuevo proyecto. Borra el contenido y pega el código de abajo.
  2. Configuración del proyecto (engrane) → Propiedades del script → Añadir propiedad: nombre CLAVE, valor una contraseña larga inventada por ti. El ID del archivo de Drive ya viene incluido en el código; solo cámbialo si usas otro archivo.
  3. Implementar → Nueva implementación → tipo Aplicación web. Ejecutar como: Yo. Quién tiene acceso: Cualquier persona.
  4. Pulsa Implementar y autoriza los permisos (si ves «app no verificada»: Avanzado → Ir al proyecto). Es tu propio script.
  5. Copia la URL de la aplicación web, pégala arriba con la clave y pulsa Probar conexión.
  6. Si luego editas el código: Implementar → Administrar implementaciones → Editar → Nueva versión; si no, la URL sigue usando el código anterior.
